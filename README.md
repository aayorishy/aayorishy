## 🧩 Projects

<p align="center"><sub>三个项目，一个理由：让 Typecho 好看一点。</sub></p>

<img src="./assets/projects-showcase.png" width="100%" alt="YUME — Typecho 主题 / MoePanel — Typecho 后台 / YumeEditor — Markdown 编辑器" />

### 🌸 [YUME](https://github.com/aayorishy/Typecho-Yume) <sub>`Typecho 主题` · `Typecho 1.3+` · `PHP 8.1+`</sub>

> 轻量、可定制的 ACG / 游戏 / 代码 Typecho 主题。

A light, dreamy theme for ACG / game / code blogs: card-style home page, soft pastel palette, grid-paper background and a marquee that never sits still. This is the theme living at [ayko.cn](https://ayko.cn) right now.

### 🐾 [MoePanel](https://github.com/aayorishy/Typecho-MoePanel) <sub>`Typecho 插件` · `Typecho 1.2+` · `PHP 8.1+`</sub>

> Typecho 的 KOOK 一体化控制台：Mac 风格后台、KOOK 登录、WebSocket Bot、身份组、欢迎消息与 DeepSeek 角色扮演。

A Mac-style admin console that pulls KOOK into the same room as your blog — KOOK OAuth login, a WebSocket bot, role groups, welcome cards, and a DeepSeek role-play assistant in the sidebar.

### ✏️ [YumeEditor](https://github.com/aayorishy/Typecho-YumeEditor) <sub>`Typecho 插件` · `基于 AAEditor` · `Apache-2.0`</sub>

> 为 Typecho 与 Yume 主题打造的轻量 Markdown 编辑器，基于 AAEditor 二次开发。

A lightweight Markdown editor built on AAEditor: code fences, container blocks, MathJax and Mermaid stay clean in the source, while the preview matches the front end you actually publish.
